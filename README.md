# Continuous Exam-Identity Drift Detector

A system for continuously monitoring behavioral signals such as keystroke dynamics, mouse behavior, and writing style to detect possible changes in a user's identity during an online exam.

## Project Structure

- `backend/features/` — Contains feature-extraction functions for keystroke, mouse, and stylometry signals.
- `backend/fusion/` — Contains the fusion logic that combines behavioral features into a single score.
- `docs/` — Contains research, documentation, and project-related documents.
